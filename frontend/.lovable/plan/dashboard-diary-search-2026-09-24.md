# Dashboard diary search

## What will change
- Add a compact search field above the open diary, with a search icon and accessible clear button.
- Filter saved entries instantly by title or content, without changing or rewriting stored diary data.
- Reset the visible page and scroll position safely when the search results change.
- Keep the existing 3D open-book presentation and scroll-controlled page-turn animation for filtered results.
- Show a small, visually consistent no-results state when nothing matches.

## Motion and responsive behavior
- Animate the search field into view and smoothly reveal the clear control and result state.
- Size and position the search interface for phone, tablet, and desktop without covering the diary.
- Respect reduced-motion preferences.

## Validation
- Test matching by title and content, clearing the query, page turning through filtered results, empty results, and responsive layouts.
